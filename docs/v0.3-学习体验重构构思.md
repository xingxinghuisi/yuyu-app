# 语屿学习体验重构构思（v0.3）

> 日期：2026-10-08
> 背景：用户实测 v0.2 后提出三点——①书太少 ②学习界面没有详细解释 ③不要输入假名的题型。
> 输入：竞品深度研究（MOJi/开心词场/墨墨/百词斩/Duolingo/LingoDeer/WaniKani/jpdb/Bunpro，见 artifact《日语背词App竞品研究》）
> 　　　＋ GitHub 开源项目调研（见 workspace/research-jp-oss.md）

## 核心判断

| 用户反馈 | 竞品结论 | 我们的解法 |
|---|---|---|
| 书太少（只有 N5–N1 五本） | MOJi 100+ 本按考试维度组织；开心词场 1000+ 本按考试/教材/场景分 | 三维词书体系：考级线 / 教材线 / 场景线，订阅制 |
| 学习界面没有详细解释 | MOJi 详情页（音调标注、日文释义、例句）；开源 10ten 的信息架构（声调＋活用还原＋分组释义＋汉字拆解）可直接抄 | 「音·形·义·用·记」五模块详情页，卡片轻量＋"详解"分层 |
| 不要输入假名 | 没有一个主流竞品把键盘打字当主力题型；WaniKani 强制输入是其最大争议点 | 砍掉打字题型，换三档自评＋选择题轮换，零输入 |

## 一、词书体系：从 5 本到三维书架

- **考级线**：N5–N1（现有）＋ 各级高频 Top500/1000 ＋ JLPT 真题词汇冲刺
- **教材线**：新标日初级/中级、大家的日语（按课同步——学生党刚需，巨大流量入口）
- **场景线**：旅游 / 商务 / 日常口语 / 动漫
- **机制**：订阅制（借鉴开源 nihongo-vocabook：官方书＋用户自建分享）；免费版每日 30 新词上限（借鉴墨墨稀缺机制），Pro 无限＋全书架
- **内容管线**：N4–N1 中文释义继续补；教材词书按课表整理（只用词表，不抄释义/例句，避版权雷）
- **注意**：墨墨的日语词书本次未能验证、开心词场疑似已下架——对标其模式而非产品本身

## 二、单词详情页：「音·形·义·用·记」

学习卡片保持轻量（别一次全倒出来），点"详解"展开完整页：

- **音**：发音（先 TTS 顶着，后期真人）＋ 音调标注 ⓪①② ＋ 慢速跟读
- **形**：汉字拆解（部首/笔画）＋ 动词/形容词活用形
- **义**：词性 ＋ 多义项分开展示（中文＋简易日文释义）
- **用**：2–3 条例句（中文译文＋振假名）→ 例句中文管线要补；搭配/近义辨析（高阶，Pro）
- **记**：助记（谐音/联想/词根拆解），UGC 众包——被采纳奖励（借鉴墨墨"采纳+1上限"飞轮）

信息架构直接参考 10ten-ja-reader（GPL-3.0，只抄设计不抄代码）。

## 三、题型：零打字

- **新词学习**：卡片展示 → 三档自评「认识 / 模糊 / 不认识」（Anki 式：先心里回想，再翻卡），零输入
- **小测/复习**：看词选义、看义选词、听音选义三种选择题轮换——借鉴 MOJi"12 题型组队"，防"熟悉度幻觉"（只看选择题会越背越觉得自己会了）
- **斩词分流保留**：第一遍三档，认识的直接毕业
- **未来**：字段遮挡自测（开源 lincw6666/japanese-vocabulary-app：遮汉字/假名/释义，心里默念再揭开）——比打字友好的主动回忆
- 发音保留跟读（Web Speech），不考核拼写

## 四、Session 重构：「15 分钟小岛」

1. **定量**：默认每日 30 新词（免费上限，Pro 自定义/无限）
2. **节奏**：学 5 词 → 快闪小测 → 学 5 词 → 小测……（借鉴开心词场"学测一体"闯关感，代替现在的每 10 词一测）
3. **收尾**：session 完成 → 岛屿添砖/种樱花（养成可视化，直接呼应"筑一座日语之岛"，竞品没有的差异化）＋ 打卡海报分享
4. **复习**：SM-2 → **FSRS**（开源 py-fsrs，MIT，`pip install fsrs`，同等记忆率复习量少 20–30%）；复习用选择题＋自评混合；错词自动进错题本 / Ghost 复活（借鉴 Bunpro）

## 五、激励与留存（轻量先行，重的不做）

- 做：岛屿养成、连续打卡 streak、打卡海报分享
- 以后：排行榜/自习室轻社交（MOJi 验证过）、PK 竞技场（重，P2 之后）
- 不做：Duolingo 式红心体力（伤体验）、试用转扣费套路（舆情风险）
