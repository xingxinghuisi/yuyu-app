# 小测改选修复（v1.3.1）

随堂小测和模考原先在首次选择后立即禁用所有选项。现在当前题在点击「下一题」或「交卷」前可以反复改选，选中样式与辅助技术状态随之更新；进入下一题后保留前题答案。每题只记录最后一个答案，不因改选增加提交题数，仍由原后端在交卷时统一判分。提交开始后锁定会话，防止重复交卷。

没有增加返回前题的导航，也没有改动立即判分的学习/复习流程。PWA 缓存更新为 `yuyu-v26-quiz-answer-change`，我的页版本更新为 `1.3.1`。

验证：使用与 `tests/map-browser.cjs` 相同的 Python 依赖与 Playwright 环境运行 `node tests/quiz-browser.cjs`。测试使用真实 Chrome、FastAPI 和 `data/map-tests` 隔离数据库，覆盖 390/1280px 下随堂小测与模考的看词选义、看义选词、听音选义，错误选择后反复改选、触屏/键盘操作、唯一选中态、最终提交内容及真实 3/3 判分、重复交卷保护。测试禁用外部音频播放，不使用线上账户。

部署沿用 `feat/anime-archipelago` 分支和原有 Docker 流程，保留 `.env` 和 `data/`，无需迁移数据库。
