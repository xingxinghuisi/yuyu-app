# 发音音量与随堂小测

## v1.6.0

登录后的右上角「音量」可以随时打开，学习、复习、例句、随堂听音小测共用同一发音音量。「我的 → 发音设置」也可以调整，并同步当前页面的滑杆。默认100%，范围0—200%，0为静音；偏好保存在本浏览器，刷新后恢复，已打开的同源标签页也会同步。不改变系统、其他应用或完整考试录音播放器的音量。

录音通过 Web Audio GainNode 调整，超过100%时增强较轻的录音，压缩器限制峰值。只处理同源录音；浏览器不支持或尚未允许 Web Audio 时保持普通录音播放，避免连接未运行的音频上下文造成无声。音频节点随播放结束或切换断开，并复用一个音频上下文。系统回退朗读使用 SpeechSynthesisUtterance.volume，其上限为100%；增强录音的200%设置不会把系统朗读传入非法音量值。[音频增益接口](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/createMediaElementSource)、[系统朗读音量范围](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisUtterance/volume)。

随堂小测现在点击选项即核对答案：答对显示绿色反馈约0.7秒；答错标红所选项、标绿正确项，同时显示正确答案，约1.5秒后自动进入下一题。反馈期间锁定答案；也可点下一题立即继续。最后一题自动交卷，结果页保留错题的题干、所选答案与正确答案。核对失败时停留当前题供重试，不假定答对、不自动跳题。

`POST /api/quiz/check` 仅允许当前账号查询以 `instant_feedback: true`、指定学习词列表创建的小测。它不消耗题目，不修改学习记录；最终仍通过已有 `/api/quiz/submit` 汇总计分、加入复习。普通词汇测验及私人 JLPT 考试继续在交卷后查看答案。页面切换或结束小测后，延迟响应和自动跳题回调不能覆盖新页面。

验证包含音量/回退/节点生命周期单元测试、判题权限及只读性测试、真实后端与浏览器的手机/桌面小测流程、网络失败重试与晚到响应；音量浏览器测试使用本地合成 WAV，采样验证95%到200%时实际音频信号约为2.1倍，并检查即时调节、静音、刷新恢复及两个设置入口同步。测试数据库和音频夹具均与线上数据隔离。

现有网站 VPS 更新程序即可；不需要重做或上传发音文件，也不需要重新识别试卷。
