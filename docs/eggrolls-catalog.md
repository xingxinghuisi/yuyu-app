## 数据迁移

旧库 14,445 条记录中，11,057 个 ID 明确映射到新源的 10,632 条独立笔记。
另有 9 条同形同音但不同义项的上游笔记独立保留，不复制旧进度到这些未学义项。
旧库其余 3,388 条不再作为活动词汇；其定义进入 `retired_words`，学习状态与收藏进入 `vocab_user_archive`，完整原库还留有备份。

首次升级先通过 SQLite 在线备份保留含 WAL 页的完整运行库：
`/data/backups/app-before-eggrolls-853798a-v1.db`。Docker 默认对应宿主机 `data/backups/`。备份存在时不覆盖。
迁移在单次事务内执行；失败回滚；修订标记使重复启动不重复迁移。

同一用户的多个旧记录对应同一笔记时，保留最近更新的完整 FSRS 状态，不相加间隔或熟练度。
收藏取并集并保留最早时间；学习日志不删除，旧 ID 保存在 `original_word_id`。
旧 API 词条 ID 可通过 `word_aliases` 访问新词条，评分、收藏和指定词条测验均解析别名。
已学总数可能因合并重复词、归档旧源独有词而减少，这不代表历史日志被删除。

主词书使用上游等级与顺序。教材/场景精选只保留原清单在新源中的对应词并标注为交集，入口 ID 保持兼容。
新源没有英文释义；英语偏好下没有英文的内容显示中文，避免空白卡片。

## 音频

10,641 条笔记均有单词音频引用，对应 10,599 个不同文件，均在固定版本媒体树中找到。
作者说明单词绝大部分为真人录制，例句是 VOICEPEAK 合成；本次只接入单词音频。
首次播放按需下载到 `/data/audio-cache/eggrolls/`，核对 Git blob SHA-1 后才保存；之后从本地缓存播放。
冷缓存需要服务器能访问 `raw.githubusercontent.com`，失败时回退已有合成语音或浏览器 TTS，不声称回退也是真人。

## 验证与恢复

迁移测试覆盖重复状态合并、收藏并集、日志原编号、未映射状态归档、备份、幂等和异常回滚。
音频测试覆盖校验、缓存命中、路径拒绝和错误响应不落盘。
运行：`python -m unittest discover -s tests -p "test_vocab*.py"`。

部署仍使用原分支和 Docker Compose，无需删除挂载数据。不要用删库的方式升级。
恢复时先停止容器并额外保存升级后的数据库，使用对应旧版本代码和备份库共同恢复后启动；仅回退代码不足以回退数据。
