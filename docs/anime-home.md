## 顺序解锁与玻璃效果修复（v1.2.3）

海图严格按 N5 → N4 → N3 → N2 → N1 推进：只有所有前序词书已学完，下一岛才会解锁。旅人与当前课程停在最早尚未完成的可用岛屿。书架仍可自由选级；高阶词书已有的学习记录完整保留，但不再跳过地图关卡。即使高阶词书已学完，前序未完成时其地图标签、节点与入口仍显示锁定。

底栏、打卡卡片和课程/进度浮层移除蓝色着色，改用中性透明渐变和降低饱和度的背景模糊。其他页面底栏保留跟随主题的玻璃效果；低端设备与静谧模式使用半透明中性色以保持清晰，继续停用模糊与动画。PWA 缓存更新为 `yuyu-v23-ordered-islands`。

新增检查覆盖每一级解锁边界、越级学习/完成、旅人实际位置及锁定入口。真实 API 学习一个 N1 词后，N5 旅人/课程保持不变，N1 仍锁定且已学记录可见。13 项模型与 SW 检查通过。

岛屿详情已移至底部原生 dialog 抽屉：点击岛屿插画、标签、节点或旅人展开，点击外部、关闭按钮或 Esc 收起。保留键盘焦点约束与返回、背景滚动锁定、地图位置恢复，离开首页会清理抽屉；减少动态偏好停用滑动。手机探索页移除下方常驻手记和额外底部留白，320/390px 宽、844px 高时为单屏海图，详情内部独立滚动。学习、复习、生词本、考试与养成入口保留在抽屉内；地图课程卡可继续直接进入学习。

真实 HTTP 浏览器检查覆盖 320/390/768/1440px 所有岛屿标签和节点、三种关闭方式、焦点返回、打开/关闭前后地图位置、学习后词数持久化与路由滚动锁清理。11 项模型/SW 检查通过，PWA 缓存升级为 `yuyu-v22-island-sheet`，加入 `map-sheet.css`。

本版在原生 HTML/CSS/JS 首页上实际实现用户参考图的动漫绘景方向，沿用 FastAPI、SQLite、PWA、词书进度和原有学习/复习流程，无新增生产依赖、无数据库迁移。项目结构与 API 审计见 [上一版记录](archipelago-home.md)。

## 美术与交互

海面、N5 樱花岛、N4 鸟居岛、N3 富士岛、N2 红叶岛、N1 雪见岛和旅人是七份独立素材，五座岛与旅人保留透明通道；没有把完整效果图铺成背景。素材由内置 imagegen 基于用户提供的参考图生成，编辑模式、逐层生成；完整提示词见 [anime-art-prompts.json](anime-art-prompts.json)。未引入第三方素材包或外部 CDN。素材不含文字和功能控件。

`map-art.js` 管理构图与分层，`anime.css` 管理手机沉浸海图和桌面海图/手记布局；路径使用独立 SVG，标签、节点、岛屿点击区、旅人和课程入口使用 HTML 按钮。标签保留完整键盘入口，点击插画也能打开对应岛屿详情。手机首屏浮层包括真实打卡、每日词数目标、当前航段、已学进度、到期复习和四项导航。

进度来自 `/api/books` 与 `/api/home/summary`，每 30 词派生一航段。没有用参考图中的 12 天、15 分钟、320 XP 或“第 3 课”替代真实数据；项目目前没有对应课程或 XP 数据模型。解锁只影响地图展示，书架仍能自由选级；已有高阶学习进度保留。

## 性能

WebP 分为 560/1120px 岛屿和 720/1440px 海面，旅人 340px。普通手机 1 倍像素密度使用约 0.91 MB 的美术资源；较高像素密度约 2.63 MB。Save-Data 或 ≤4 线程设备强制小图，并自动停用动画和背景模糊。静谧模式和系统减少动态均有效，页面后台暂停动画。没有常驻 Canvas/WebGL 绘制循环。

Service Worker 升至 `yuyu-v22-island-sheet`，预缓存新脚本/样式、小图与旅人，其他同源静态资源按需缓存。登录与学习 API 继续走网络，离线显示重试状态，不展示伪造进度。

## 运行

与原项目相同，安装 `backend/requirements.txt`（Windows 另需 `tzdata`），设置本地 `DATA_DIR` 与 `JWT_SECRET`，然后：

```text
python -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8767
```

打开 `http://127.0.0.1:8767/`。正常使用本地账号注册/登录；本次内置浏览器已经登录独立测试账户，测试数据位于 `data/map-tests/`，与生产数据分开。

## 与参考图仍有的差距

岛屿与海浪已是精细动漫绘景，但光照、海岸接缝与视角尚未完全统一。踏石和鸟群仍为较简洁的 SVG；旅人只有起伏动画，尚无逐帧行走、船只巡航或跨岛镜头。桌面采用海图与手记并排，手机使用单屏海图与底部详情抽屉。真机 Safari、低端安卓和长时间耗电尚未实测。

发布分支为 `feat/anime-archipelago`。服务器更新时沿用该分支并重建 Docker 容器，保留现有 `.env` 和 `data/`。
