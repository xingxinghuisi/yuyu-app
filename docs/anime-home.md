# 语屿 · 动漫群岛首页

本版在原生 HTML/CSS/JS 首页上实际实现用户参考图的动漫绘景方向，沿用 FastAPI、SQLite、PWA、词书进度和原有学习/复习流程，无新增生产依赖、无数据库迁移。项目结构与 API 审计见 [上一版记录](archipelago-home.md)。

## 美术与交互

海面、N5 樱花岛、N4 鸟居岛、N3 富士岛、N2 红叶岛、N1 雪见岛和旅人是七份独立素材，五座岛与旅人保留透明通道；没有把完整效果图铺成背景。素材由内置 imagegen 基于用户提供的参考图生成，编辑模式、逐层生成；完整提示词见 [anime-art-prompts.json](anime-art-prompts.json)。未引入第三方素材包或外部 CDN。素材不含文字和功能控件。

`map-art.js` 管理构图与分层，`anime.css` 管理手机沉浸海图和桌面海图/手记布局；路径使用独立 SVG，标签、节点、岛屿点击区、旅人和课程入口使用 HTML 按钮。标签保留完整键盘入口，点击插画也能打开对应岛屿详情。手机首屏浮层包括真实打卡、每日词数目标、当前航段、已学进度、到期复习和四项导航。

进度来自 `/api/books` 与 `/api/home/summary`，每 30 词派生一航段。没有用参考图中的 12 天、15 分钟、320 XP 或“第 3 课”替代真实数据；项目目前没有对应课程或 XP 数据模型。解锁只影响地图展示，书架仍能自由选级；已有高阶学习进度保留。

## 性能

WebP 分为 560/1120px 岛屿和 720/1440px 海面，旅人 340px。普通手机 1 倍像素密度使用约 0.91 MB 的美术资源；较高像素密度约 2.63 MB。Save-Data 或 ≤4 线程设备强制小图，并自动停用动画和背景模糊。静谧模式和系统减少动态均有效，页面后台暂停动画。没有常驻 Canvas/WebGL 绘制循环。

Service Worker 升至 `yuyu-v21-anime`，预缓存新脚本/样式、小图与旅人，其他同源静态资源按需缓存。登录与学习 API 继续走网络，离线显示重试状态，不展示伪造进度。

## 运行

与原项目相同，安装 `backend/requirements.txt`（Windows 另需 `tzdata`），设置本地 `DATA_DIR` 与 `JWT_SECRET`，然后：

```text
python -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8767
```

打开 `http://127.0.0.1:8767/`。正常使用本地账号注册/登录；本次内置浏览器已经登录独立测试账户，测试数据位于 `data/map-tests/`，与生产数据分开。

## 验证

- `node --test tests/map-model.test.cjs tests/map-sw.test.cjs`：11 项通过，包含进度/解锁边界和新美术预缓存。
- `python tests/api-bridge.py --smoke`：项目原有后端回归全部通过，包括 FSRS、词书、考试、生词本、打卡与统计。测试需要额外安装 `httpx`，不加入生产依赖。
- `node tests/map-browser.cjs http://127.0.0.1:8767`：实际 Chrome + HTTP + FastAPI + 隔离数据库，320/390/768/1440px 全部岛屿标签与节点可点击，旅人和课程入口能进入原有学习；一词学习进度真实持久化，原有路由、打卡海报、静谧模式、请求竞态、失败重试、PWA 注册及离线重载通过。测试使用 Playwright 与本机 Chrome。
- `data/map-preview/` 保存实际页面截图，不是设计稿。浏览器预览使用相同真实应用。

## 与参考图仍有的差距

岛屿与海浪已是精细动漫绘景，但光照、海岸接缝与视角尚未完全统一。踏石和鸟群仍为较简洁的 SVG；旅人只有起伏动画，尚无逐帧行走、船只巡航或跨岛镜头。桌面采用海图与手记并排，手机保留首屏海图及下方详细数据。真机 Safari、低端安卓和长时间耗电尚未实测。

改动位于本地分支 `feat/anime-archipelago`，未推送 GitHub。
